# D&D Duel Engine

Автономный headless-движок дуэлей двух воинов 1-го уровня по выбранным правилам 2024 года. Rust владеет состоянием боя, генератором случайных чисел и всеми ресурсами. Gymnasium вызывает ту же библиотеку в своём процессе через `ctypes`. Rust-ядро собирается без сторонних crates.

## Запуск

Из корня проекта на этом Mac достаточно выполнить:

```sh
make check
make episode
./target/release/duels 5000000 42
PYTHONPATH=python .venv/bin/python examples/episodes.py --policy mlp --episodes 5000 --seed 42
```

Для чистого checkout нужны стабильный Rust с Cargo, C linker, Python 3.10+ и Make. Подготовьте Python через `python3 -m venv .venv` и `.venv/bin/python -m pip install -r requirements.txt`, затем выполните `make check`. Для запуска только Rust достаточно `cargo run --locked --release --bin duels -- 10000 42`. На этом Mac Make сам выбирает установленный внутри проекта toolchain. Аргументы CLI — число дуэлей и начальный `u64` seed. Каждый бой получает seed предыдущего плюс один (с переходом через границу u64). После 2048 решений в одном бою CLI учитывает его в `capped`.

## Участники и турнир

| Слот | Снаряжение и стиль | Хиты / КД | Действие оружием | Мастерство |
|---|---|---|---|---|
| 0, щитовик | Кольчуга, щит, Defense | 12 / 19 | Длинный меч в одной руке, +5, 1d8+3 | Sap |
| 1, лучник | Клёпаная кожа, Archery, 20 стрел | 12 / 15 | Длинный лук, +7, 1d8+3 | Slow |

Собственные числовые пресеты и идентификаторы книги, черт и оружия находятся в [presets.rs](../src/presets.rs). Поле `book` принимает строковый ID источника. Следующую книгу можно добавить вместе с её пресетами и исполнителями выбранных эффектов. В текущую сборку входят только перечисленные эффекты двух бойцов.

[tournament.rs](../src/tournament.rs) задаёт условия старта и победы. На линии от 0 до 60 футов бойцы начинают на отметках 15 и 45, с полными ресурсами, без предварительных эффектов. Первым ходит победитель броска инициативы d20 + модификатор Ловкости. Равенство разрешает равновероятная жеребьёвка из того же RNG. Бой заканчивается немедленно при 0 HP, в том числе во время реакции. Оба получают реакцию с начала боя.

## Решение игрока

В Rust `Duel::new(seed)` останавливается на первом решении. `actor()` возвращает слот принимающего решение или `None` после окончания. `turn()`, `phase()`, `fighters()` и `legal_mask()` доступны без продвижения времени и RNG. Бит `i` соответствует `ACTIONS[i]`. Передайте разрешённый `Action` в `step` и получите событие. Незаконный выбор возвращает ошибку и сохраняет весь бой, включая RNG. Для self-play выбирайте политику по `actor()` каждый раз, в том числе внутри чужого хода.

| ID | Выбор | Что меняется |
|---|---|---|
| 0 / 1 | Приблизиться / отступить | Один шаг 5 футов. Бойцы не занимают одну позицию. |
| 2 | Атаковать оружием | Тратит действие, выстрел также тратит стрелу при любом исходе. |
| 3 | Безоружный удар | На дистанции 5 футов, +Сила и мастерство к попаданию, 1 + Сила урона. |
| 4 | Второе дыхание | Одно бонусное действие и один из двух зарядов. Лечение 1d10+1 до максимума HP. |
| 5 | Завершить ход | Возобновляет движение, действие, бонусное действие и реакцию нового владельца хода. |
| 6 / 7 | Атака по возможности / пропуск | Выбор защитника перед шагом из 5 в 10 футов. |

Щитовик реагирует мечом, лучник — безоружным ударом. Пропуск сохраняет реакцию. Попытка атаки тратит реакцию даже при промахе. При нокауте участники остаются на прежних позициях. Если оба в строю, ядро завершает отложенный шаг, затем возвращает управление владельцу хода.

Натуральные 1 и 20, сравнение с КД, дополнительные кости урона при крите и помеха при стрельбе вблизи разрешаются в [ядре](../src/lib.rs). Sap даёт помеху на следующую атаку цели до начала следующего хода владельца меча. Помехи не складываются. Пресет лучника использует Slow при каждом попадании с уроном. Скорость цели снижается на 10 футов до начала следующего хода лучника.

## Gymnasium

```python
from duel_env import DuelEnv

with DuelEnv() as env:
    obs, info = env.reset(seed=42)
    env.action_space.seed(7)
    while True:
        action = env.action_space.sample(mask=obs["action_mask"])
        obs, reward, terminated, truncated, info = env.step(action)
        if terminated or truncated:
            break
```

Пример запускается с `PYTHONPATH=python`. Агент получает выигравший инициативу слот на весь эпизод. Это даёт ему первый осмысленный выбор даже при возможном нокауте с одного удара. При смене seed меняются и слот, и исходные броски. Встроенный соперник играет до следующего решения агента, включая момент, когда агенту предложена реакция. Для независимых политик обоих игроков Python предоставляет `NativeDuel(seed)` с методами `snapshot`, `step`, `bot_action` и `close`.

Наблюдение содержит `seat`, снимок `state` из 24 целых и `action_mask` из 8 бит. Порядок полей публикует `duel_env.STATE_FIELDS`, порядок действий — `duel_env.ACTIONS`. Слоты бойцов в наблюдении фиксированы. Фазы 0, 1 и 2 обозначают ход, окно реакции и конец. В финальном состоянии `actor=-1`, маска пустая. До окончания `winner=-1`. Бюджет движения, эффекты и оставшиеся ресурсы видны агенту.

Победа/поражение дают +1/−1 и `terminated=True`. Допустимый промежуточный выбор даёт 0. По умолчанию после 256 решений агента эпизод получает `truncated=True`, если бой ещё идёт. На границе лимита нокаут имеет приоритет. Выбор закрытого бита внутри Gym сохраняет состояние боя и тратит один шаг лимита со штрафом −0,05. Запросы к Rust через `NativeDuel` отклоняют такой выбор ошибкой. После окончания или усечения для нового эпизода нужен `reset`.

## Проверки и измерения

`make check` запускает Rust-тесты, Gymnasium `check_env` и сравнение 64 эпизодов с двухсторонним интерфейсом ядра на каждом решении агента. Сверка правил с Natural 20 и официальным SRD описана в [rules-check.md](../rules-check.md).

Замер 18 ноября 2026, macOS arm64, Rust 1.100.0 release, один поток боя. Для Gym использованы Python 3.14.4, Gymnasium 1.4.0 и NumPy 2.5.5. Время учитывает создание боёв и выбор действий, для Gym также переходы через FFI и ответы соперника.

| Режим | Объём | Результат |
|---|---:|---:|
| Два Rust-бота | 3 × 5 000 000 дуэлей с seed 42 | медиана 63,02 млн решений/с и 2,33 млн дуэлей/с |
| Gym + политика Rust-бота с обеих сторон | 5 000 эпизодов | 128 593 шага агента/с |
| Gym + NumPy MLP 24→32→8, batch 1, соперник Rust | 5 000 эпизодов | 57 725 шагов агента/с |

Во всех трёх нативных запусках совпали 135 279 517 решений и счёт 4 075 505 : 924 495. Ни один бой не достиг лимита. Нативный счётчик включает каждое движение, конец хода и ответ на реакцию обоих игроков. В строках Gym единица измерения — один вызов `env.step` агентом, включая обработанные внутри него решения соперника. MLP со случайными фиксированными весами выбирает из легальных действий по softmax. Это замер инференса вместе со средой, без обучения. Результат зависит от машины, политики и длины боёв.

## Границы первого среза

Одна открытая линия с видимостью, фиксированная экипировка и два боевых профиля. У лука вся арена в обычной дальности. Поддержано указанное мастерство для одного используемого оружия каждого воина. При создании полноценного персонажа воин выбирает больше видов оружия. Вне среза остаются смена оружия, отдельный выбор применить Slow, Dash, Disengage, Dodge, взаимодействия с объектами, захваты, толчки, укрытия, сложная местность, видовые и фоновые черты, прочие классы, заклинания, отдых и спасброски от смерти. Эти действия отсутствуют в маске. Процент побед характеризует данный пресет арены, состав действий и две эвристики.
