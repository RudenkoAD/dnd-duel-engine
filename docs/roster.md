# Арена пятого уровня

Каждый из двух игроков выбирает класс и подкласс. Оба начинают дуэль на уровне 5 с полным запасом ресурсов своей сборки. Все 36 сборок доступны на обеих сторонах, в том числе в зеркальных парах.

| Бард | Lore | Valor | Glamour |

| Друид | Land | Stars | Sea |
| Воин | Champion | Battle Master | Psi Warrior |
| Монах | Open Hand | Mercy | Elements |

| Плут | Thief | Assassin | Soulknife |
| Чародей | Draconic | Aberrant | Clockwork |
| Колдун | Fiend | Archfey | Great Old One |
| Волшебник | Evoker | Abjurer | Diviner |

Номера в заголовке соответствуют аргументам терминала `--subclass` и `--opponent-subclass`. В Python функция `arena.native.roster()` возвращает идентификатор, класс и описание каждой сборки. Идентификаторы 0–35 идут по строкам таблицы слева направо. Например, 13 — воин Battle Master, 35 — волшебник Diviner. Идентификаторы целей по-прежнему отсчитываются от действующего игрока.

```python
from arena.native import Batch

with Batch(1) as duel:
    duel.reset_builds([42], [[13, 35]])
    state, legal, actor, result = duel.observe()
```

Выбор подкласса входит в наблюдение сети. Это позволяет двум персонажам одного класса принимать разные решения. Маска действий учитывает экипировку, ресурсы, допустимые цели и текущий этап выбора. Архивные веса можно запускать на этой арене. Оценки из прежних турниров относятся к старому составу участников. ## Измеренный баланс

Односторонним финишем считался нокаут, при котором у победителя осталось хотя бы 75% максимальных хитов. Временные хиты исключены, ничьи входят в знаменатель. Для каждой из 66 межклассовых пар меняли стороны, сохраняя арену и зерно. В полном составе у каждой пары классов проверены девять сочетаний подклассов. Во всех трёх форматах использовали одни и те же четыре освещённые карты.

| Состав | Усиленный бот против себя | Сеть 2×256 против себя |
| --- | ---: | ---: |
| 12 исходных сборок, прежнее распределение уровней 1–5 | 61,8% | 48,2% |
| 12 исходных сборок, все на уровне 5 | 49,7% | 34,7% |
| 36 сборок, все на уровне 5 | 55,3% | 38,0% |

При переходе от прежнего формата к новому доля таких нокаутов снизилась у обоих контроллеров. При фиксированном пятом уровне добавление подклассов увеличило её. В новом составе усиленный бот показал перевес не менее 80% очков у одного из классов в 41 паре из 66. У сети таких пар 27. Победа даёт одно очко, ничья — половину. Сеть update-2901 обучалась на прежнем составе. Для этой проверки её веса на новых входных признаках обнулили. Всего проведено 69 696 боёв.
