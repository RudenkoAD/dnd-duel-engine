# Специалисты против чемпиона update-1300

Обе политики учили PPO управлять одной стороной по всему диапазону из 12 классов, 5 равных уровней и 4 карт. В каждом из 2 880 сочетаний класс обучаемой стороны и класс чемпиона заданы отдельно. Каждое сочетание играет пару боёв с одним зерном и сменой мест вместе с классами. Порядок сочетаний перемешивается на каждом полном проходе. Отдельные пространства зёрен X1T у запусков 401 и 402 задают независимые обучающие бои, а генератор PyTorch использует соответственно 401 и 402.

В каждой реакции и обычном ходе чемпион выбирает допустимое действие с максимальным логитом через тот же NumPy-код, что при игровой инференции. PPO выбирает действие обучаемой стороны стохастически и получает её решения, включая реакции. Оба запуска делают по 200 обновлений по 384 боя и используют одинаковые гиперпараметры. Штраф за повтор идентичного действия в том же состоянии хода равен 0,02, за ничью по лимиту — 0,35. Вес вспомогательного слагаемого при выборе цели снаряда равен 0,04. Сохраняются обновления 50, 100, 150 и 200.

Выбор чекпойнта использует отдельное фиксированное пространство X1D. На каждом срезе и для обеих начальных политик запускаются 5 760 боёв. Обе стороны выбирают действие жадно. Победа даёт очко, ничья — пол-очка. Выбирается максимум из четырёх сохранённых обновлений, при равенстве выбирается раннее. Начальная политика служит контрольной точкой. Оценка на финальных зёрнах проводится после выбора.

Для воспроизведения нужен релизный ABI 2002 (`make release`) и Python с NumPy и PyTorch. Исходный запуск использовал библиотеку с SHA-256 `621964e798659ba534fab6c8494664c8e7f9d91abb9a4e28ccb0ed9f40888e3f`, Python 3.10.15, NumPy 2.2.6 и PyTorch 2.9.1. Укажите новые каталоги, если они уже существуют.

```sh
export PYTHONPATH=python
champion=training/runs/league/checkpoints/update-1300.npz
python3.10 training/specialist_play.py --champion "$champion" --start "$champion" \
  --run-dir /tmp/arena-specialist-champion --run-id 401
python3.10 training/specialist_play.py --champion "$champion" \
  --start training/runs/viewer_relative/control.npz \
  --run-dir /tmp/arena-specialist-control --run-id 402
```
