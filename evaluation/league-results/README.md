# Финальная парная проверка лиги

Домен **L1F**, 5,760 боёв на каждую пару политик. Расписание покрывает упорядоченные пары классов, одинаковые уровни и все четыре арены. Для каждой пары бойцов сыграны обе рассадки. Один сид используется также для обратного порядка классов.

Очки за бой равны 1 за победу, ½ за ничью и 0 за поражение. Итоговый балл поровну учитывает средние очки против трёх нейросетевых соперников и очки против встроенного усиленного бота. Оба чекпойнта действуют жадно по разрешённым действиям. Случайный соперник равномерно выбирает разрешённый индекс. Строки league-update отражают дополнительные бои с ранними чекпойнтами этого запуска и имеют нулевой вес в итоговом балле.

Для 95%-х интервалов бутстрэп сохраняет вместе обе рассадки, оба порядка классов и результаты против всех соперников на одном сиде. Страты заданы уровнем, ареной и совпадением классов. Это описательные интервалы.

Хэши чекпойнтов и полное расписание находятся в `manifest.json`. В сжатых файлах перечислены исходы и причины завершения для каждой рассадки.

## Воспроизведение

Запустите из корня репозитория после сборки release-библиотеки (`make release`). Для повторного расчёта используйте пустой каталог вывода.

```bash
PYTHONPATH=python .venv/bin/python evaluation/league_holdout.py \
  --checkpoint training/runs/league/checkpoints/update-1300.npz \
  --sha256 96f9bddabc0eeff4a70c111db443dea064490c6e576ff8bb569966024cb26e31 \
  --league-anchor 600 8b7413ab80e2ec07cd3a1f9a5563ae6572fcdeec6d6f6e5d6948c07af7ec11a7 training/runs/league/checkpoints/update-0600.npz \
  --league-anchor 1200 5ee4280f3b6f0e2272b1a97e8d6ed3ead8c2532a10293a0356de9936c424d286 training/runs/league/checkpoints/update-1200.npz \
  --batch-size 512 --jobs 3 \
  --random --output evaluation/league-results-reproduced
```
