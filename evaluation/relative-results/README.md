# Независимая проверка политики ABI 2002

Кандидат набрал **99.36%** очков против random при **98.36%** у исходного чекпойнта ABI 2001 и **59.26%** в очном матче с адаптированным чекпойнтом. В фазе 80 он выбрал себя 0 раз из 30476 случаев, когда был доступен противоположный дуэлянт. Всего зафиксировано 30687 решений фазы 80.

Домен сидов **s3-final**. На каждую строку приходится 5760 боёв. Перебраны упорядоченные пары классов, одинаковый уровень обоих бойцов и все четыре арены. Каждая пара использует один боевой сид в двух рассадках.

Кандидат и адаптированный чекпойнт выбирают действие с максимальным логитом среди разрешённых. Исторический контроль использует исходный чекпойнт и исходное наблюдение ABI 2001. Random равномерно выбирает индекс в списке допустимых физических действий. В одинаковых боях обе версии получают одинаковый поток случайных чисел для соответствующего места.
