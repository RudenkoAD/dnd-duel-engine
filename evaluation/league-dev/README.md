# DEV-оценка лиги

Для выбора чекпойнта используются только сиды домена `L4D`. Расписание включает все 12×12 упорядоченных пары классов, уровни 1–5 у обоих дуэлянтов, четыре карты и обе рассадки. Перестановки классов используют общий сид. Поэтому у матча стартовой модели с её копией точный баланс побед и поражений по всей выборке. На каждого соперника приходится 5 760 боёв и 1 560 разных сидов. Во всей серии чекпойнтов сохраняются одинаковые игровые условия.

Фиксированная лига даёт одинаковый вес трём обученным политикам ABI 2002. Это стартовая модель `d81965d6…`, контроль `99b99391…` и промежуточная модель целевого прогона `c9be34b3…`. Все обученные политики выбирают допустимое действие по максимальному логиту. Нативный эксперт оценивается отдельно.

В журнале `curve.json` каждый матчап содержит число побед, ничьих и поражений, долю побед и очки (доля побед плюс половина доли ничьих). Баланс — среднее очков лиги и эксперта. Чекпойнты оцениваются каждые 100 обновлений. Материальный прирост каждой серии фиксируется при достижении не менее 0,50 п. п. относительно её предыдущего материального максимума. Плато считается достигнутым, когда у баланса, лиги и эксперта прошло по четыре таких интервала без материального прироста. Чекпойнт выбирается по наибольшему балансу, при равенстве берётся наиболее ранний.

Критерий остановки впервые выполнен на обновлении **1300**. К этому моменту прошло 7, 4 и 7 интервалов без материального прироста по балансу, лиге и эксперту соответственно. Обновление 1300 также установило максимумы всех трёх серий. Всего в DEV сыграно 322 560 боёв.

Баланс вырос с 59,18% до 62,26%. Чекпойнт для отдельной проверки имеет SHA-256 `96f9bddabc0eeff4a70c111db443dea064490c6e576ff8bb569966024cb26e31`.

Воспроизведение из корня репозитория, после `make release`.

```sh
export PYTHONPATH=python OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1
.venv/bin/python evaluation/league_curve.py --output /tmp/league-curve.json
.venv/bin/python evaluation/league_curve.py --output /tmp/league-curve.json \
  --update 100 --checkpoint training/runs/league/checkpoints/update-0100.npz
```

Повторите вторую команду для каждого следующего сохранённого чекпойнта, соблюдая порядок обновлений.
