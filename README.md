# D&D Duel Engine

Локальные дуэли D&D 2024 на клеточной карте с высотой, укрытиями и скрытой информацией. У каждого из 12 классов есть три подкласса. В новых дуэлях оба бойца всегда пятого уровня. Rust рассчитывает броски, цену действий и доступные решения. Терминал, Gymnasium и пакетное обучение получают состояние с точки зрения игрока, которому предстоит действовать. [Все подклассы и их способности](docs/roster.md)

## Установка

На Linux или macOS понадобятся стабильный Rust с `cargo` в `PATH`, системный C-компоновщик, Make и Python 3.10 или новее. Из корня репозитория создайте окружение для Gymnasium и NumPy и соберите движок.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
make release
```

Cargo собирает движок без сетевого доступа. Для обучения потребуется также PyTorch.

## Играть в браузере

Из каталога проекта запустите локальный стол «Рубеж».

```sh
make web WEB_ARGS="--checkpoint training/runs/roster-2901-league/checkpoints/update-1000.npz"
```

Сервер слушает только локальный интерфейс. Клиент поставляется вместе с движком, работает без CDN и не требует npm. Добавьте `--port 8766` в `WEB_ARGS`, если порт 8765 занят. [Открыть арену](http://127.0.0.1:8765/)

Первый бой начинается на «Янтарной заставе» волшебником 5-го уровня против воина, с зерном 11. В «Новой дуэли» можно выбрать класс и подкласс каждого бойца, сторону и зерно. Пустое зерно создаёт случайную партию.

- Наведите мышь на клетку, чтобы прочитать местность, высоту стены и укрытие от известной позиции соперника. Поверните стол или включите срез стен для выбора клетки за препятствием.
- Во вкладке «Шаг» нажмите клетку и проверьте путь перед подтверждением. Длинный маршрут оценивает расход по видимому рельефу. Игра перепроверяет каждый шаг и останавливается при прерывании.
- Выберите заклинание, подтвердите его объявление и следуйте решениям движка. Клик по фигурке указывает существо, клик по полю выбирает точку. При выборе высоты подсветка показывает сечение области на поверхности поля.
- Бой останавливается на каждом вашем ответе, включая реакции и ход спутника. Хроника показывает наблюдаемые перемещения, расход ваших ресурсов и изменения хитов. Нажмите имя бойца для просмотра его листа.
- Обновление вкладки восстанавливает текущую партию, пока сервер работает и сессия хранится в памяти. Сервер держит до 32 последних использованных партий. Для остановки нажмите Ctrl+C в терминале.

## Играть в терминале

Из каталога проекта запустите дуэль против той же сети.

```sh
make play PLAY_ARGS="--checkpoint training/runs/roster-2901-league/checkpoints/update-1000.npz"
```

Терминал предложит выбрать бойцов. Введите порядковый номер пункта меню, чтобы выбрать действие или ответ на реакцию. В Python `step()` принимает идентификатор действия из маски текущей фазы, а в JSON-записи этот идентификатор хранится в поле `action`. Ход допускает несколько решений, например выйти из-за стены, выпустить стрелу и отойти. Инициативу определяет ядро. Для матча с заданными бойцами и сохранения повтора выполните команды ниже.

```sh
make play PLAY_ARGS="--checkpoint training/runs/roster-2901-league/checkpoints/update-1000.npz --class fighter --subclass 2 --opponent wizard --opponent-subclass 3 --seat east --seed 42 --save /tmp/duel.json"
make play PLAY_ARGS="--replay /tmp/duel.json"
```

В архивном примере волшебник выбирает клетку и высоту для Огненного шара и тратит реакцию на Щит. Числа за сторону игрока в этой проверке вводил сценарий.

```sh
make play PLAY_ARGS="--replay examples/replays/evoker-vs-trained-policy.json"
```

## Политика и обучение

Одна сеть играет всеми 36 сборками. Финальный чекпойнт `update-1000.npz` использует ABI 2002, 1 024 входных признака и два скрытых слоя по 256 нейронов. На каждом шаге сеть оценивает 128 вариантов. Их смысл задаёт текущая фаза. Например, при выборе цели Magic Missile можно назначить один дротик и получить следующий выбор или отправить все оставшиеся дротики в одну цель. Движок выдаёт маску разрешённых вариантов отдельно для каждого шага. [Входные признаки и маска](docs/coverage/observation.md) · [Выбор действия](python/arena/policy.py)

Финальная сеть сыграла 384 000 учебных боёв в обычной лиге на всех 36 сборках пятого уровня, со сменой сторон на каждой паре и с охватом пяти арен. В независимой проверке она набрала 57,03% очков против исходного чекпойнта 2901 и 68,71% против усиленного бота. Ничья приносила половину очка. [Веса финальной сети](training/runs/roster-2901-league/checkpoints/update-1000.npz) · [Оценка силы и баланса](evaluation/roster-2901-league/README.md)

SHA-256 финального файла — `608facd39535f804f9304783093f2590c74ed66966654ff51bb667c480ceda17`.

```sh
python3 -c 'import hashlib, sys; print(hashlib.sha256(open(sys.argv[1], "rb").read()).hexdigest())' \
  training/runs/roster-2901-league/checkpoints/update-1000.npz
```

В ABI 2002 цель 0 обозначает своего бойца, 1 — противника, 2 — своего спутника и 3 — спутника противника. При реакции отсчёт ведётся от игрока, принимающего решение. [Обучение и история весов](training/README.md) · [Протокол оценки](evaluation/README.md)

В терминале соперник выбирает наиболее вероятное допустимое действие. Флаг `--sample` включает выборку из распределения сети с учётом заданного зерна. При запуске без `--checkpoint` терминал и веб-интерфейс загружают более раннюю сеть с двумя слоями по 128 нейронов из `models/arena_policy.npz`. Её выбрали из двух вариантов дообучения на относительных целях, которые суммарно сыграли 138 240 учебных дуэлей за 6 минут 40 секунд. В обоих случаях обеими сторонами управляли сети. Четверть учебных дуэлей проходила между разными уровнями. [Веса по умолчанию](models/arena_policy.npz) · [Журнал дообучения](training/runs/viewer_relative/training.jsonl.gz)

В архивном тесте на прежних сборках сеть выиграла 5 697 из 5 760 дуэлей против равномерно случайного соперника (98,91%). Ещё 52 закончились вничью, 11 — поражением. При зачёте половины очка за ничью сеть набрала 99,36% против случайного соперника, 69,09% против стандартного и 67,73% против усиленного. На тех же боях прежняя политика ABI 2001 набрала соответственно 98,36%, 66,08% и 65,35%. [Парные сравнения и выбор целей по сторонам](evaluation/relative-results/README.md)

Первый раунд self-play на ABI 2001 занял 17 минут 27 секунд и 341 760 дуэлей. Его отдельная проверка содержит разбор по классам, уровням и картам. [Исторический отчёт](evaluation/self-play-results/REPORT.md) · [Журнал первого раунда](training/runs/self_play/training.jsonl)

### Пробный запуск обычной лиги

Для этого примера понадобится Python 3.10. Команды создают отдельное окружение с PyTorch и выполняют одно обновление на 32 боях. Обучение стартует с весов финальной сети и новым оптимизатором. Две замороженные версии широкой сети служат соперниками.

```sh
run_root=$(mktemp -d)
python3.10 -m venv "$run_root/venv"
"$run_root/venv/bin/python" -m pip install -r requirements.txt 'torch==2.8.0'
make release
PYTHONPATH=python "$run_root/venv/bin/python" training/league_play.py \
  --start training/runs/roster-2901-league/checkpoints/update-1000.npz \
  --anchor training/runs/long-width/checkpoints/update-0967.npz \
  --anchor training/runs/long-width/checkpoints/update-1934.npz \
  --run-id 2902 --run-dir "$run_root/league" \
  --updates 1 --batch 32 --minibatch 256 --epochs 1 --threads 2 \
  --checkpoint-every 1 --matched
```

Журнал и новые веса появятся в `$run_root/league/training.jsonl` и `$run_root/league/checkpoints/update-0001.npz`. Путь `--run-dir` должен быть новым. [Параметры полного обучения](training/runs/roster-2901-league/README.md)

## Правила и интерфейсы

- На четырёх освещённых картах и в тёмном варианте бастиона поле занимает 9 × 7 клеток по 5 футов. Препятствия высотой 10 футов дают укрытие, потолок находится на высоте 30 футов. У каждого существа есть положение и размеры. Местоположение скрывшегося противника может быть неизвестно действующему игроку. [Правила арены](docs/arena-rules.md)
- Два основных бойца начинают с полными ресурсами. Потеря последних хитов завершает дуэль. Одновременный нокаут и достижение лимита в 60 индивидуальных ходов или 800 решений дают ничью. [Сборки и их прогрессия](docs/coverage/creation-ledger.md) · [Матрица покрытия](docs/coverage/README.md)
- В терминале доступны действия, реакции, выбор цели и ресурсов. Например, дротики Magic Missile можно направить в нескольких существ, а при Shatter указать ранг, клетку и высоту центра. [Турнирная трактовка Suggestion](docs/suggestion.md)
- Rust и Python предоставляют оба места в дуэли. В пакетном интерфейсе `arena.native.Batch.observe()` возвращает признаки, маски, действующие места и исходы. `step()` принимает одно решение на дуэль, в том числе в чужой ход. Значение `-1` пропускает строку пакета. [Поля наблюдения](docs/coverage/observation.md)
- В Gymnasium среда `gym.make("arena.gym_env:DndArena-v0")` принимает место игрока через `reset(options={"seat": 0})` и функцию соперника через `opponent_policy`. Базовый соперник доступен без весов сети. [Среда Gymnasium](python/arena/gym_env.py)
- Простая линейная дуэль двух воинов по-прежнему доступна через отдельную среду. [Описание и команды](docs/line-duel.md)

## Проверка

```sh
make check
./target/release/arena_bench 50000
```

`make check` собирает нативную библиотеку, запускает Rust-тесты и Python-тесты Gymnasium и пакетного ABI. `arena_bench` замеряет решения двух нативных тактических ботов на всех классах и уровнях. В этот замер входит стоимость их выбора действий.
